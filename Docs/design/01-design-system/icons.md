# Icons

All UI icons are [Lucide](https://lucide.dev) outline icons: 24×24 viewBox, stroke `currentColor`, stroke width 1.75 (2 for small 16px icons), round caps and joins. Use the Lucide package of the target stack (`lucide-react` on the web; a Lucide Flutter package or exported SVGs on Android) by the names below.

Names were matched from the approved frames' SVG paths. Some boards drew circles and squares as single paths, so a few names are matched by shape (for example `lock`, `circle-check`). Where Lucide renamed an icon in a newer version, use the current equivalent.
