# Images

The approved designs use **no raster images**. Every photo, video still and map on the boards is a flat placeholder (token `placeholder` `#E6ECF3` blocks with a Lucide icon) or an inline SVG illustration, already contained in each `screen.html`.

In the product, evidence media come from signed read URLs (`GET /projects/{id}/evidence`, 15-minute expiry) and maps from the map component; there are no marketing photos to ship. Public-site imagery (hero photos, testimonials) was not designed and is a gap in PACKAGE-REPORT.md.
